# ✨ 키키의 마법 우체국

> 하늘섬 곳곳으로 편지를 배달하는  
> 감성 판타지 콘솔 턴제 RPG 프로젝트

---

## 📖 프로젝트 소개

`키키의 마법 우체국`은  
플레이어가 마녀 **키키**가 되어 하늘섬 주민들에게 편지를 배달하며  
전투, 성장, 기억 조각 수집을 진행하는  
C# 기반 콘솔 턴제 RPG 프로젝트입니다.

배달을 진행하며 다양한 몬스터와 전투를 펼치고,  
새로운 스킬과 장비를 해금하며 키키를 성장시킬 수 있습니다.

---

## 🎮 주요 기능

### ✦ DAY 시스템
- DAY 진행 구조
- 하루 시작 / 하루 마무리
- DAY별 이벤트 및 연출

### ✦ 우체국 탐험
- 콘솔 맵 이동 (W/A/S/D)
- 편지 정리대 / 상점 / 기억 조각 관리
- 여러 퀘스트 동시 진행 가능

### ✦ 퀘스트 & 배달 시스템
- 배달 퀘스트 수락
- 배달 물품 구매
- 목적지 이동 및 배달 완료
- 퀘스트 완료 보상 지급

### ✦ 턴제 전투 시스템
- 플레이어 / 몬스터 턴 진행
- 스킬 사용
- MP 관리
- 도망가기 기능
- 전투 메시지 출력
- 몬스터 패턴 기반 전투

### ✦ 성장 시스템
- 경험치 및 레벨업
- 레벨별 스킬 해금
- 빗자루 강화
- 방어구 장착 시스템

### ✦ 기억 조각 시스템
- 특정 퀘스트 완료 시 기억 조각 획득
- 기억 조각 수첩 열람 가능
